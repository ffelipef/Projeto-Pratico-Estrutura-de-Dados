# 🧙‍♂️ Sistema de Batalha RPG com Estruturas de Dados

Projeto prático de Estrutura de Dados em Java que simula batalhas de RPG por turnos. Desenvolvido para aplicar conceitos como **lista encadeada**, **fila** e **pilha** de forma manual, com foco no aprendizado e na programação orientada a objetos.

---

## ⚙️ Funcionalidades

- Cadastro e login de jogadores
- Criação e gerenciamento de personagens
- Combates em turnos (PvP ou PvE)
- Inventário e habilidades por lista encadeada
- Fila de turnos dinâmica
- Registro de ranking por pilha
- Interface via terminal (linha de comando)

---

## 🧠 Estruturas de Dados Utilizadas

- **Lista Encadeada:** para personagens, habilidades e itens
- **Fila Encadeada:** controle de ordem de turno na batalha
- **Pilha Encadeada:** histórico e colocação final dos combatentes

---

## 🚀 Fluxo de Jogo

1. Jogador cadastra ou faz login
2. Cria ou seleciona um personagem
3. Escolhe modo de batalha (PvP ou PvE)
4. A batalha se desenrola em turnos
5. Vencedor é anunciado e ranking exibido

---

## 📁 Organização

- `Jogador.java`: cadastro, autenticação e seleção de personagem
- `Personagem.java`: atributos e ações do personagem
- `ListaEncadeada.java`: estrutura de lista personalizada
- `FilaEncadeada.java`: gerenciamento de turnos
- `PilhaEncadeada.java`: controle de derrotas/ranking
- `Main.java`: interface principal do jogo

---

## 🎯 Objetivo

Este projeto tem como foco:
- Reforçar o uso de estruturas de dados
- Desenvolver a lógica de sistemas baseados em turnos
- Estimular boas práticas com POO em Java
